# 采集数据查看器（Windows 端）

连自己的采集服务器，按采集点/任务查看照片视频，批量下载、批量删除，并且能把采集点信息一键填到美团的「申请采集点」表单里。

## 运行 / 打包

```powershell
pip install pillow pyinstaller
python viewer\app.py

# 打包（文件夹版，别用 onefile：单文件会解压到 %TEMP%，部分电脑被拦截）
powershell -ExecutionPolicy Bypass -File viewer\build.ps1
```

## 界面

- **左**：采集点列表（门店 / 采集员 / 时间 / 场景分类 / 面积 / 任务数 / 文件数 / 大小），最左列可勾选
- **右**：文件列表按「区域 / 任务」分组，勾选后可批量下载；点照片在下方预览
- **底部三行**：
  - 文件：下载勾选文件 / 全选 / 删除勾选文件 / 下载当前选中文件
  - 采集点：下载勾选采集点 / 全选 / 删除勾选采集点 / 下载这个采集点全部 / 打开下载目录
  - 美团：**申请采集点（自动填表）**

## 申请采集点（自动填表）

1. 左边选中一个采集点
2. **先完全退出 Edge**（任务栏右键退出；同一份配置不能两个进程同时用）
3. 点「申请采集点（自动填表）」
4. 脚本会用**你电脑上 Edge 的真实配置**启动浏览器 → 只要这台电脑的 Edge 登录过 EgoOps，打开就是登录态
5. 自动打开任务分配页 → 点「申请采集点」→ 填 名称 / 地址 / 面积 / 场景分类
6. 窗口留着核对、补媒体文件，然后手动提交

换电脑也能用：新电脑第一次用 Edge 登录一下 EgoOps 即可，不用拷 token/cookie。

- 登录态来源：`%LOCALAPPDATA%\Microsoft\Edge\User Data\Default`
- 没登录会停下来等，登录后自动继续
- 字段匹配不到时，会把弹窗里所有控件打印到 `egoops_fill.log`，把日志发我即可校准
- 媒体文件目前仍需在页面里手动选择
